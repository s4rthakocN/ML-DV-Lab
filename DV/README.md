# Interactive Dashboard with Filters and Slicers

## Aim
Build a retail dashboard and add slicers for region, category, and order date.

## Software
- Microsoft Power BI Desktop
- CSV dataset included in this folder

## Procedure
1. Open Power BI Desktop.
2. Select **Home → Get data → Text/CSV**.
3. Select `data.csv` from this folder and choose **Load**. For Practical 2, choose **Transform Data** instead.
4. Open the **Report** view and create the visual(s) listed below.
5. Add clear titles and check that the fields use the correct data types.
6. Save your work as `04_interactive_dashboard.pbix` in this folder.

## Suggested visual setup
- Add a **Card** for total Sales and another for total Profit.\n- Add a **Clustered column chart:** Axis = Category; Values = Sum of Sales.\n- Add three **Slicer** visuals: Region, Category, and OrderDate.\n- Select each slicer and test how it changes the charts and cards.

## Result
The visual(s) show the requested information and can be explored in Power BI.
